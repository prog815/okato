# 🗺️ Интерактивный справочник ОКАТО

Онлайн-справочник по Общероссийскому классификатору объектов административно-территориального деления (ОКАТО). Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/okato/](https://prog815.github.io/okato/)

Этот справочник — для тех, кто сталкивается с указанием кодов административно-территориального деления в статистической отчётности, кадровых и бухгалтерских документах, архивах и адресных системах. Главная задача — помочь быстро найти корректный 11-значный код ОКАТО по названию или самому коду и скопировать его в один клик.

## Что кодирует ОКАТО

**ОКАТО** — общероссийский классификатор, в котором записаны объекты **административно-территориального деления**. Он отвечает на вопрос **«к какой административной единице относится территория»**.

В текущем снимке справочника содержится порядка **170 тысяч записей**. Классификатор представлен плоским списком (без дерева в интерфейсе), но с сохранением иерархии через структуру кода:

- **Субъект РФ** (2 цифры, например `01`).
- **Район / город** (5 цифр, например `01 201`).
- **Поселение** (8 цифр, например `01 201 802`).
- **Сельский населённый пункт** (11 цифр, например `01 201 802 001`).

Код любого объекта строится по схеме `TER(2) + KOD1(3) + KOD2(3) + KOD3(3)` и всегда имеет длину 11 цифр (незначащие части заполняются нулями).

> **Важно про ОКТМО.** ОКАТО и ОКТМО — это разные классификаторы. ОКАТО описывает административное деление (для статистики, старых форм и архивов), а ОКТМО — муниципальное деление (для налогов, бюджета и ЭДО). **Их коды не взаимозаменяемы.** Если в форме запрашивается ОКТМО, используйте [соответствующий справочник](https://prog815.github.io/oktmo/).

> **Особенность нумерации.** В ОКАТО своя нумерация субъектов, которая отличается от кодов в ИНН или адресных справочниках. Например, код `01` — это Алтайский край (а не Адыгея), `45` — Москва (а не Курганская область). Не подставляйте коды регионов из ИНН в поиск ОКАТО.

- сверить реквизиты территории в договорах и старых актах.

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по коду.** Введите `01201802001` или `01 201 802 001` (с пробелами, точками или без). Поиск строго с начала кода.
- **Поиск по названию.** Одно или несколько слов в любом порядке по логике «И»: `Залесово`, `Алейский район`.
- **Смешанный запрос.** Введите `01 Залесово` — найдёт все объекты, где код начинается с `01` **и** в названии есть «Залесово».
- **Копирование в один клик.** Клик по коду копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Иерархия.** В карточке объекта показан его родитель (вышестоящая территория). Клик по родителю ищет его в справочнике, позволяя подниматься по иерархии вверх.
- **Фильтры.** Чекбоксы для выбора уровней (субъект / район / поселение / сельский НП) и выпадающий список для выбора субъекта РФ. Бейджи уровней и субъектов в карточке тоже кликабельные.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере. В текст автоматически подставляются наименование, ссылка, код, уровень, субъект и родитель.
- **Прямые ссылки на коды.** Каждый код можно передать через `?code=…` в адресе.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## Примеры запросов

- `01201802001` или `01 201 802 001` — село Алейский (Алтайский край).
- `Москва` — все административные объекты с этим словом.
- `45` — коды, начинающиеся с `45` (Москва и её территории).
- `Алтайский край` + фильтр «Субъекты РФ» — все записи первого уровня этого региона.

**Популярные коды (в нумерации ОКАТО):**
- `01` — Алтайский край;
- `40` — Санкт-Петербург;
- `45` — Москва;
- `67` — Севастополь;
- `99` — Еврейская автономная область.
